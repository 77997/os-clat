os-clat package repository

This site is a package repository for OPNsense. It holds one plugin, os-clat, a 464XLAT CLAT (RFC 6877): on an uplink that carries only IPv6 it gives the devices behind the firewall IPv4 through the provider's NAT64. The plugin is built for OPNsense 26.7. The source is at github.com/77997/os-clat.

Current version: os-clat %%VERSION%%

Install

  1. Bring OPNsense up to date: System > Firmware > Status, Check for updates. OPNsense refuses to install a plugin while an update of OPNsense itself is pending.
  2. Open a shell on the firewall as root: sign in on the console or over SSH, then choose option 8 (Shell) in the menu, and paste this one line. It adds this repository and the fingerprint of its signing key. It works on a firewall that has only IPv6. 
    mkdir -p /usr/local/etc/pkg/fingerprints/os-clat/trusted /usr/local/etc/pkg/fingerprints/os-clat/revoked && fetch -o /usr/local/etc/pkg/fingerprints/os-clat/trusted/os-clat.fingerprint %%SITE_URL%%/os-clat.fingerprint && fetch -o /usr/local/etc/pkg/repos/os-clat.conf %%SITE_URL%%/os-clat.conf
  3. In the web interface open System > Firmware > Plugins. At the end of the list click Click to view the community plugins. Find os-clat (repository os-clat), click + and confirm the Third party software notice with Install.
  4. The plugin is under Services > CLAT.

Updates

New versions arrive with the normal firmware updates: System > Firmware > Status, Check for updates. Nothing has to be repeated in the shell.

Signing key

The repository is signed. The one line above installs this fingerprint (SHA-256 of the public key), and OPNsense accepts packages from this repository only when their catalogue is signed with that key:

%%FINGERPRINT%%

Remove

Remove the plugin under System > Firmware > Plugins, then remove the repository:

rm -f /usr/local/etc/pkg/repos/os-clat.conf && rm -rf /usr/local/etc/pkg/fingerprints/os-clat
